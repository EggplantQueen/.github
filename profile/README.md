## Welcome to EggplantQueen

This is the public GitHub home of **CN1 / EggplantQueen** — an independent internet-native project built around one character and a growing ecosystem of connected experiences.

CN1 currently spans:

- Telegram community tools and bots;
- games and arcade experiments;
- multiplayer / combat work through **Lower Rooms**;
- **the CLUB**, an online social and music space;
- a reusable 3D CN1 character foundation;
- public visual storytelling and project development.

The goal is not to look bigger than we are.

The goal is to **build real things and show the work**.
